# V6.1.4 — Nested Modal Navigation

Dashboard drill-down modals now remain open when an ESO report is opened from them.

Flow:
- Dashboard → KPI/Department drill-down → ESO Detail
- Closing ESO Detail returns to the same KPI/Department drill-down.
- The drill-down keeps its component state, including search/filter state and current scroll state while mounted.
- Closing the drill-down separately returns to Dashboard.

Applied to dashboard KPI report lists and Department Performance drill-downs. No database migration is required.
