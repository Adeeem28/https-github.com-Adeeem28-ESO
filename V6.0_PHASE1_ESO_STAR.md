# V6.0 Phase 1 — ESO Star

- Database migration adds `is_starred`, `starred_by`, `starred_at` to `eso_reports`.
- Management, Admin and Super Admin can award/remove an ESO Star from ESO Details.
- Starred reports show a gold star marker and recognition banner.
- All ESO Submissions includes an `ESO Stars` filter.
- Existing reports remain unstarred by default.

Database migration was applied to Supabase project `uwrhwskwnyguktddfhmy` before this package was created.
