# V6.1.3 Performance Optimization

- Login no longer waits for Notifications and VoE requests before rendering the app.
- `/api/data` no longer creates signed Storage URLs for every ESO photo during login/refresh.
- ESO photo signed URLs are loaded on demand only when an ESO detail modal is opened.
- Photo endpoint preserves company/plant/user/task access scope.
- Existing database schema and data are unchanged.
